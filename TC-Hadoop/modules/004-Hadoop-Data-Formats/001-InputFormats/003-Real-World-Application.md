## Real World Example

- In a real world scenario, developers are using a combination of file format according to their work need. If the need is to get the data in human readable format then text or CSV files are a good choice. If the need is to transfer the data over the network from source to destination with high speed then the AVRO files are good to go. If the need is to analyse the data using hive or spark, then parquet files or RC files are good choices as their read performance is higher than other file formats.
