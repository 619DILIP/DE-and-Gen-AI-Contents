## Summary 

- Hadoop mainly supports 7 types of file format for storing data. Each file format has its own usage in hadoop and one file format can be converted to another file format with or without using any tool. 

- Text/CSV files used to store the text based data and are human readable. 

- JSON/AVRO files are used to store the data in key-value pairs and are row-oriented files.

- RC/ORC and Parquet files are column-oriented files, which stores the table column data in rows. These files are highly compressed binary files and has high reading and retrieving data performance.
