## What is Cloud Computing?

Cloud computing is the on-demand delivery of computing services such as servers, storage, databases, networking, software, analytics, and intelligence over the Internet with pay-as-you-go pricing.

Instead of owning and maintaining physical data centers and servers, organizations can rent technology services from a cloud provider.

In simple terms:
- Traditional model: Buy servers → Install software → Maintain hardware → Upgrade manually.
- Cloud model: Access services over the Internet → Pay only for usage → Scale instantly.

Cloud servers are hosted in global data centers managed by providers. Users access these services through web interfaces, APIs, or command-line tools.

---

## Key Characteristics of Cloud Computing

1. On-Demand Self-Service  
   Users can provision computing resources automatically without human interaction from the provider.

2. Broad Network Access  
   Services are accessible over the Internet via laptops, mobile phones, and tablets.

3. Resource Pooling  
   Providers serve multiple customers using shared infrastructure.

4. Rapid Elasticity  
   Resources can scale up or down instantly based on demand.

5. Measured Service  
   Usage is monitored and billed based on consumption.

---

## Advantages of Cloud Computing

### 1. Backup and Restore
Data stored in the cloud can be backed up and restored quickly using automated systems.

### 2. Improved Collaboration
Teams can share files and work on the same documents in real time from different locations.

### 3. High Accessibility
Data and applications can be accessed anytime, anywhere with an internet connection.

### 4. Reduced Maintenance Costs
Organizations do not need to maintain physical hardware or perform manual software upgrades.

### 5. Scalability
Resources can be increased during peak demand and reduced during low usage.

### 6. Mobility
Employees can access applications and data using mobile devices.

### 7. Large Storage Capacity
Cloud providers offer virtually unlimited storage options.

### 8. Enhanced Security
Cloud providers implement encryption, firewalls, identity management, and monitoring tools.

---

## Types of Cloud Deployment Models

### Public Cloud
Services are delivered over the public Internet and shared among multiple customers.
Example providers: AWS, Microsoft Azure, Google Cloud.

### Private Cloud
Infrastructure is dedicated to a single organization and may be hosted on-premises or by a third party.

### Hybrid Cloud
A combination of public and private cloud environments, allowing data and applications to move between them.

---

## Cloud Service Models

### Infrastructure as a Service (IaaS)
Provides virtual machines, storage, and networking.
Users manage operating systems and applications.

### Platform as a Service (PaaS)
Provides a development platform where developers build and deploy applications.
The provider manages infrastructure.

### Software as a Service (SaaS)
Provides ready-to-use applications accessible through a web browser.
The provider manages everything.
