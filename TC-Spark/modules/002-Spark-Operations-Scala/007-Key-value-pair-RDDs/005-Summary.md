## Summary

- In Spark, there is one special type of RDD which holds key-value pairs known as pair-RDD. Similar to regular RDDs, there are some transformations and actions functions that can be applied on pair-RDDs. 

- Examples of Transformation functions that can be applied on pair-RDDs are `reduceByKey()`, `combineByKey()`, `aggregateBykey()`, etc. 

- Examples of Action function that can be applied on pair-RDDs are `collectAsMap()`, `countByKey()`, `lookup()`, etc.
