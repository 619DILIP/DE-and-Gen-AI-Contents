## Summary 

- Login to Amazon AWS and choose `Create bucket` option in s3 console. Enter name of the bucket and choose it AWS region. 

- After creating s3 bucket, upload your file to the s3 bucket by creating a folder there.

- At EMR console, choose `Create cluster` to open the Quick Options wizard. Then enter name of your cluster,  choose s3 bucket you created and choose the Spark option under applications to install spark on your cluster. 

- For Software Configuration, choose a Release option. After that select other necessary options and then click on Create cluster option.

- After clicking on Create cluster, go back to the S3 console and you will see the output directory there.
