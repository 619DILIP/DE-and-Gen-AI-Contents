Data types enforce the expected types of values inserted into a table. SQL provides a standard list of data types which can be categorized into 3 main categories, each with its own subcategories.

- Character types
  - Fixed-length
  - Variable-length
- Numeric types
  - Decimal
  - Integer
  - Floating point
- Temporal types
  - Date
  - Time
  - Timestamp
