### Completion Time
30 minutes

### Lecture Focus
Version Control - Introduce the objective of Version Control
Centralized vs Decentralized - Compare and contrast centralized and decentralized Version Control Systems (VCS)
git workflow - Introduce basic commands/concepts of git use: init, add, commit, push, and pull.

### Prerequisites
N/A

### Learning Objectives
Clearly describe the git workflow. Outline the process of adding files to staging, saving those changes to a commit, and pushing one or more commits to a remote repository. A clear understanding of those basic steps, along with graphics or illustrations to help visualize the process, will make further practice and use of git tools easier for associates to understand.

### Related Content

### Discussion Questions
- In what circumstances would a centralized VCS be preferable to a decentralized one?
- What advantages does version control offer to working in a team development environment?
- What version control best practices can you implement in your personal project work that will help develop good habits when working with a development team in a professional setting?
