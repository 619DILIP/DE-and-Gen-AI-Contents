## Applying These Practices to a Data Pipeline

A data engineering team running a pipeline across EC2 or Lambda, S3, and RDS applies these practices together rather than in isolation. The EC2 instance is assigned a narrowly scoped IAM role, its security group only allows the specific network access it needs, the S3 bucket it reads from and writes to remains private with encryption enabled, and the RDS database it connects to is only reachable from that specific EC2 instance, not from the open internet. Account level access is protected with MFA, and logging is enabled so that any unusual access pattern can be investigated. None of these individual steps are complex on their own, but together they form a meaningfully more secure system than any single measure alone would provide.
