In this module, we learned:

- Cloud security practices apply the customer side of the shared responsibility model to specific services.
- EC2, S3, and RDS each have specific, practical security configurations worth applying by default.
- Encryption at rest and in transit protects data both while stored and while moving across a network.
- Logging and monitoring support detecting and responding to unusual or unauthorized activity.
- Multi factor authentication significantly reduces the risk of unauthorized account access.

With the core services and their security covered, the next module brings them together, using AWS Lambda to connect storage, permissions, and a database into a single working pipeline.
