# Real World Application for Pylint
Most organizations are going to have some form of coding standard they expect their employees to adhere to, even if it is just the standard conventions of the language. When these standards are followed it becomes significantly easier to review, maintain, and fix code bases. The shared understanding of how code should be written also provides a common ground for developers when they need to collaborate. You don't have to spend time deciding how to name variables, how to structure your source code, or how to save the work. You simply let the standards dictated by your organization/language do that for you.
