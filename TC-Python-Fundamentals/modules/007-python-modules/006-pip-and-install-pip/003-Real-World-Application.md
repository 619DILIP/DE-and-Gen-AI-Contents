# Real World Application for Pip
The world of software is ever evolving, but even new and innovative ideas tend to need resources created by those who came before us. When building an application there will almost always be someone who has had a similar need as you and already built a solution to the problem. These solutions typically end up as packages stored in PyPi, free for you to implement in your own project. The benefit of this system is you can focus on your application's specific logic and features, utilizing third party packages of software that is ready to go that has been developed by someone else. Some common use cases for using third party packages:
- building web servers
- creating and executing tests
- creating more complex logs
- performing complex mathematical computations
- managing large data sets
