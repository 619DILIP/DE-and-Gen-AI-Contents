# Introduction 
JavaScript Object Notation (JSON) is one of the most common data formats used in programming. Fundamentally, a JSON is simply a formatted string, and since just about every programming language has a way to interact with strings it is an ideal format for transferring data between services. The Python library comes with a module called "json" that has helper functions for creating and decoding JSONs.

JSONs support the following data types (represented in string form):
- string
- number
- boolean
- nested json (key:value pair collections)
- arrays
- null
