# What is a Module
A module is a file Python code is written in: this can be your file or a file included in the base library or third party package. The most common way of indicating you file is a module is to add the ".py" extension.

This is a useful distinction because your code is not always going to strictly work with other Python modules: sometimes you will need to load data from other files (like a csv) into your code, so if for no other reason, using the ".py" extension helps to make obvious what files have your code and which do not.
