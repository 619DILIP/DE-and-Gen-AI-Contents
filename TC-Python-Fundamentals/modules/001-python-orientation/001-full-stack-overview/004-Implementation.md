# Implementation

- The work of a full-stack developer is going to differ depending on what systems the front and back ends use, but the general kind of work is going to be the same. When working on the back end, developers are going to need to ensure that data received from the front end is transformed and validated correctly. Any interactions with databases need to be sanitized, and result sets returned from the database also need to go through a transformation process to ensure the data fits what the front end is expecting.

- In the front end, developers need to ensure that users have an intuitive and secure interface to work with your service, typically through the use of web pages. These should be hosted on a secure server that has permission to make requests to the back end. When the user makes requests to the back end, the data returned should be transformed into meaningful information displayed on the web page, if applicable.

- Again, how this plays out will vary depending on the software you work with and the services you are building. Fundamentally, your front end will facilitate user interactions, and your back end will process those actions.
