# Real World Application for Namespaces
Namespaces are useful for keeping your code organized and modular. In smaller projects you can leverage the namespaces to control access to resources in your code, and in larger projects the namespaces allow you to avoid naming conflicts and to properly share resources across modules where necessary. 

Keep in mind that whatever the scope of your code, you will need to know how the namespaces interact and how to access resources in them to ensure your code functions properly.
