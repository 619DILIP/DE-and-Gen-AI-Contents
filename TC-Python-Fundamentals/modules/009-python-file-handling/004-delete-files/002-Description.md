Python provides the option to delete files and directories via the "os" module. 

## "os" Module
The "os" module has far more functionality than just removing files and directories, but these features will be the focus of this module. The "os" module requires being imported into your code before you can use it. 

Once imported, it provides helpful methods for removing files and directories, and it also has methods for discovering what files and directories are available to you.
