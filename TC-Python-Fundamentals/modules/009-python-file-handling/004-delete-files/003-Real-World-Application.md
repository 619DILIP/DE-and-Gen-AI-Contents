Applications have a tendency to build up temporary files that become obsolete over time. Many of these apps do a good job of cleaning up these temporary files and removing them from your computer: without the cleanup your computer would slowly become inundated with unnecessary files that take up valuable space. During runtime it can also be useful to store information inside temporary files, but since these files are only temporary they should be deleted when they are no longer used. This is the benefit of deleting files programmatically: it gives you a greater flexibility in how you work with data, and helps you to keep your computer and virtual workspace organized.
